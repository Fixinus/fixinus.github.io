# Fixinus website — project instructions

## Voice: "we", not "I" — deliberate exception

Customer-facing copy on this site uses first person plural: "me" in Finnish,
"vi" in Swedish, "we" in English.

This is a deliberate exception to the global rule in ~/.claude/CLAUDE.md, which
requires first person singular in customer-facing text. Decided by Linus on
2026-08-03, for this site only.

Everything else a Fixinus customer sees — emails, invoices, työraportit, quotes
— still uses "I" / "minä". The exception does not extend past this site.

Do not "fix" the site copy to first person singular. If you have read the global
rule and are looking at "we" here, this file is the reason.
